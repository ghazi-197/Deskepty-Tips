Deskepty — Tips & Tricks

Version 3.4.0
  1. Right-click a group title — import / export, duplicate, create folder, delete.
  2. Right-click any icon — the menu changes with the icon type: .exe app, folder, Microsoft Store app, and more.
  3. Right-click empty space — the main menu.
  4. Right-click a sub folder — rename or delete.
  5. Hold the dots and drag to move Deskepty — or right-click to pick a monitor and it jumps there.
  6. The toggle button shows and hides Deskepty — press and hold to drag it, or right-click to pick a monitor and the button jumps too.
  1. System icons — add up to 12 from Settings.
  2. Power options — everything you need, one click away.
  3. A sub folder holds up to 64 icons — drag icons inside the popup to organize, right-click them for more options.
  4. Right-click empty space inside a sub folder — add apps, Store apps and games straight into it.
  5. Lock — keeps Deskepty on screen while you organize or drag apps in from Explorer.
  6. The tray icon menu — show / hide and center the toggle button, adjust its opacity — plus center main panel, restart and exit.
